Post 3 Do real ao pixel

Do mundo real ao pixel: como uma imagem se torna digital

Durante as aulas de Computação Visual, fiquei curioso sobre como uma imagem se torna digital na prática. Estamos acostumados a tirar uma foto com o celular e vê-la aparecer quase instantaneamente na tela, mas o que acontece entre a cena real à nossa frente e aquela imagem formada por pixels?

Tudo começa com a luz

Antes de existir uma imagem digital, existe uma cena sendo iluminada. A luz proveniente de uma fonte atinge os objetos e parte dessa energia é absorvida, enquanto outra parte é refletida e pode chegar ao sensor de uma câmera.

Fonte de luz → Objeto → Luz refletida → Sensor → Imagem
f(x,y) = i(x,y) × r(x,y)

Nessa expressão, i(x,y) representa a iluminação que chega ao objeto e r(x,y) representa sua refletância, isto é, quanto daquela iluminação é refletida. Isso significa que a aparência de um objeto em uma imagem não depende apenas dele, mas também das condições de iluminação.

Do sensor para o computador

O problema é que o mundo real apresenta variações contínuas, enquanto o computador precisa trabalhar com uma quantidade finita de valores. Para transformar os dados capturados pelo sensor em uma imagem digital, são fundamentais dois processos: amostragem e quantização.

Amostragem Define onde medir, escolhendo as posições espaciais registradas.
Quantização Define qual valor representar, usando níveis finitos de intensidade.

Depois desses processos, a imagem pode ser representada como uma matriz bidimensional f(x,y). Cada elemento dessa matriz é chamado de pixel, abreviação de picture element.

No fim, uma imagem é formada por números

Em uma imagem em escala de cinza de 8 bits, cada pixel pode assumir 28 = 256 valores diferentes de intensidade, normalmente de 0 a 255. O valor 0 representa o preto, 255 representa o branco e os valores intermediários correspondem aos diferentes tons de cinza. 

0    40    90
80   130   180
150  210   255

Para nós, o resultado visual é uma imagem. Para o computador, porém, ela pode ser tratada como uma matriz organizada de valores numéricos.

E depois que a imagem virou pixels?

A representação numérica permite que o computador realize operações diretamente sobre os pixels. É nesse ponto que entram as transformações de intensidade estudadas em aula.

s = T(r)

Nessa transformação, r é a intensidade original de um pixel e s é a intensidade obtida depois da transformação. Um exemplo é o negativo, que inverte as intensidades da imagem, fazendo regiões claras se tornarem escuras e regiões escuras se tornarem claras.

Também existem transformações logarítmicas e de potência, como a correção gama, que redistribuem as intensidades e podem tornar determinados detalhes mais perceptíveis. Outras técnicas, como o alargamento de contraste e a limiarização, ajudam a aproveitar melhor a faixa disponível ou a separar pixels de acordo com um valor definido.

Da realidade para uma matriz

Luz → Cena → Sensor → Amostragem → Quantização → Pixels → Processamento

Uma fotografia que parece perfeitamente contínua para nossos olhos é, para o computador, uma grande estrutura de valores numéricos. É justamente essa transformação do mundo visual em dados que permite posteriormente aumentar contrastes, destacar regiões, analisar estruturas e realizar diversas outras operações de Computação Visual.

Antes de o computador conseguir analisar uma imagem, primeiro precisamos transformar aquilo que existe no mundo real em números que ele consiga entender.
